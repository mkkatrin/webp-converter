# Конвертер

Простое приложение для macOS: перетащите файлы в окно браузера — картинки и видео превратятся в WebP, а PDF сожмутся до нужного размера.

- Картинки: JPG, PNG, HEIC (фото iPhone), TIFF, BMP, AVIF
- Видео и GIF → анимированный WebP
- Настройка качества, максимальной ширины, кадров в секунду, режим «без потерь»
- PDF: сжатие до заданного размера (по умолчанию 20 МБ). Если для этого приходится сильно жертвовать качеством, Конвертер спросит, оставить один файл или разделить на несколько
- Всё обрабатывается на вашем компьютере, файлы никуда не загружаются
- Готовые файлы сохраняются в «Загрузки/Конвертер»
- Обновляется само: при выходе новой версии в окне появляется плашка «Доступно обновление»

## Установка

Откройте **Терминал** (⌘ + Пробел → «Терминал»), вставьте эту строку и нажмите Enter:

```bash
curl -fsSL https://raw.githubusercontent.com/mkkatrin/webp-converter/main/install.sh | zsh
```

Дальше следуйте подсказкам. Установка займёт 1–5 минут.

## Запуск

Дважды щёлкните значок **Конвертер** на Рабочем столе (или найдите его в Launchpad) — конвертер откроется в браузере.
Выключается сам через пару минут после закрытия вкладки, или по ссылке «Закрыть конвертер» внизу страницы.

## Удаление

Удалите папку `webp-tool` в домашней папке, приложение «Конвертер» из папки «Программы» в домашней папке и значок с Рабочего стола.
